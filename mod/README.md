# Zero 2 · Air Actions 实验改版 v0.1.2

基于《Mega Man Zero 2》美版的主人公动作实验。原版逆向研究位于 [main 分支](https://github.com/Licheng314/Rockman-zero2/tree/main)，本分支保存独立改版源码和 IPS 补丁。

## 修改内容

- 空中按方向与冲刺进入加速冲刺，使用游戏原有冲刺姿态和残影。最多持续 18 次更新，约 0.3 秒，松开方向或冲刺提前结束，同一次跳跃只使用一次。
- 新游戏保留枪和剑的初始拥有状态与装备栏。四种武器等级预先加满，全部 10 项 EX 和 10 套装可选。EX 在菜单中启用，默认使用普通套装。
- 正常取得并装备锁链枪后，空中伸出锁链时原地滞留 30 次更新，约 0.5 秒，期间清除纵向速度和重力加速度。
- 在共享命中入口过滤敌人身体对 Zero 的常规接触伤害。
- 修复空中冲刺贴墙后重力方向错误导致的墙跳卡住或持续上飞。
- 锁链枪和盾的满级处理覆盖正常取得和旧存档恢复，避免取得武器时被原版初始化清零。

## 使用补丁

准备自己的美版原 ROM，大小为 8,388,608 字节，SHA1 为 `c4d93a58f0f82c526dec8a3fdbda170336303689`。从本仓库 Releases 下载改版补丁包，解压后执行下列命令。应用补丁只需要 Python 标准库。

```powershell
python mod/apply_patch.py "你的美版原ROM.gba" "Zero2-AirActions.gba"
```

也可以使用支持 IPS 的补丁工具应用 `mod/patches/v0.1.2/rmz2-air-actions-v0.1.2.ips`。上述 Python 工具会自动核对原版、补丁和修改后的校验值。

从新游戏开始体验新的初始成长、EX 和套装配置。原版或旧改版的即时存档可能带有旧装备、旧状态或不同版本的代码位置。

已有普通存档在本版本正常读档时会补满锁链枪和盾的等级及经验。此修复通过角色快照恢复路径验证，跨版本即时存档仍可能跳过该路径。

## 从源码构建

在仓库根目录准备 `baserom.gba`，在 `tools/bin/` 准备 Windows x64 的 `armips.exe` 和 `mgba_libretro.dll`，使用 Windows x64 Python。执行 `python -X utf8 mod/build.py`。构建会运行游戏内检查，成功后输出到 `build/mod/rmz2-air-actions-v0.1.2.gba`。

## 已验证与边界

已验证新游戏默认装备、四武器原版满级初始化、全 EX 和全套装拥有位、菜单选择、普通锁链空中滞留、回旋盾与地面出招对照、18 次更新的冲刺和残影。锁链样本使用测试内存临时装备，蓄力样本使用预置蓄力计数。碰墙后的中立、朝墙和离墙三种跳跃输入，均与原版移动代码在同一墙边状态下对照 100 次更新。

序章五组移动输入验证了身体接触过滤，其中三组实际敌弹仍各造成 2 HP 伤害，Zero 的枪仍能打倒原版目标。Boss、特殊近身攻击、所有关卡和长期游玩尚未逐项验证。碰撞过滤以对象类别和攻击描述字段为依据，特殊敌人的边界可能需要后续修正。

满级回归通过内存调用夹具执行原版武器取得函数与角色快照恢复函数，检查锁链枪和盾的实际拥有位、等级和经验。旧版本在取得锁链枪时可复现等级及经验清零，新版本两种武器取得和低等级快照恢复均通过。尚未重跑完整 NPC 对话流程。

反馈时请附原 ROM 校验值、补丁版本、模拟器版本、关卡和复现输入。关于其他改版的重合或兼容性，需要对方具体版本和修改范围后才能比较。
