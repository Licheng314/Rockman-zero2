# 向外阶段每步处理器：类型 0 的 fn[1]（0x08065BF8）

本轮解码 0x0833D990 二维分派表中类型 0 的 D=1（向外）每步处理器本体，
把 [发射初始化](semantic-parent-launch-init.md) → 每步飞行 →
[碰撞捕获回调](semantic-parent-capture-callback.md) → [向外飞行/返程](semantic-parent-outbound-terrain.md)
四段连接。证据 = 原 ROM capstone 反汇编（0x08065BF8-0x08065CF8，该函数已被
批量提取覆盖，asm/sub_08065BF8.s）。基线 SHA1 c4d93a58…。

## 已确认的类型 0 向外每步流程

```
fn[1](e):
  if (e->unk8C & 0x200) != 0: 跳过移动与采样，直接进入状态分支
  r5 = 08CFC(e->54, e->58 + K)        ; K = 池字面量（outbound 报告的 -0x800 上方 8 像素采样）
  if r5 低16位非零 (命中地形):
      D = 2（转入返程阶段）
      e[0x14] = 表[e[9]]->[8]          ; 换装 D=2 处理器（fn[2]）
      调 fn[2]（0x08065CF5）一次        ; 返程首步立即执行
      结束本轮
  else (未命中):
      if (08065A24(e) != 0):           ; ← 全局标志谓词（本项目 C 集成 #4 字节级匹配）
          127E4(e, 0x6D00)             ; 脚本切换（参数低字节 = 0）
          128D4(e)                     ; 动画推进（旧识别 Entity_UpdateAnimation）
          06E08(e+0x74, 表)            ; 六段链更新
          e[0xC0] = r5                 ; 保存最后一次地形采样结果
          e[0xD] = 3; e[0xE] = (u8)r5  ; 转入状态 3（ settle）
      else:
          垂直距离检查：e->58 与全局对象(池) ->58 的差 + 0xC000 与阈值比较
          e[0xBC] = -1（越界方向标记）或按 e[0xA] 位4 选择相对坐标源
```

## 与既有研究成果的互证

1. **0x08065A24 = 本项目 C 集成 #4**（全局标志谓词，字节级匹配）——它在 ROM 原生
   路径中被类型 0 的向外处理器调用作行为选择器。C 匹配成果与语义链首次直接接轨。
2. **0x080127E4 / 0x080128D4** = 旧识别的 Entity_SetScript / Entity_UpdateAnimation
   （本项目早期从零识别的两个函数）——在脚本切换后被调用。
3. 命中地形 → `D=2` + `e[0x14] = fn[2]` + 立即调 fn[2]——与发射初始化的
   "e[0x14] = 表[e[9]]->[4]"（D=1）机制一致：**e[0x14] 是当前阶段处理器槽，
   阶段切换时由各 fn[D] 自己换装**。这回答了 launch-init 报告的未解决项
   "e[0x14] 调用点"：它由每步处理器自身在阶段切换时覆写，调用方是通用的
   D 分派逻辑（792D4 一带的通用处理器按 D 读表调用，见 outbound-terrain 报告）。

## 阶段状态机（类型 0，综合本轮与既有报告）

```
786F0: D=1, 速度/超时/六段链初始化
  → fn[1] 每步: 门禁(0x200) → 移动 → 08CFC 采样
      命中 → D=2, e[0x14]=fn[2], 立即首步返程
      未命中 → 谓词08065A24 分流:
          置位 → 脚本0x00+动画+六段更新+D=3（settle, e[0xE]=采样值）
          清位 → 垂直距离/朝向逻辑（e[0xBC]）
  D=2 (fn[2] 0x08065CF5): 反向移动, S+12 递减 → 0 时停用/捕获交接（见 outbound/capture 报告）
  D=3 (共享 fn[3] 0x08065A05): 状态退出 → 按 e[9] 二次查表
每步中六段链的段碰撞 → 0x08079748 捕获登记回调（见 capture-callback 报告）:
  S->unk2C = 目标(类型0x22), S+0x13 = 0x10, B4/B8 = 相对偏移, 目标状态 4
```
