# 0x08004B3C/0x08004B9C 动画序列与帧步进：资源链最后一级

承接 [图形库切换器 127E4](semantic-script-bank-switch.md)。本轮解码库内切换
0x08004B3C 与帧步进器 0x08004B9C，**资源链（类型→库→序列→帧）至此全通**。
证据 = [anim-sequence-check.py](semantic-data/anim-sequence-check.py)（13/13 通过）+
[anim-sequence-evidence.json](semantic-data/anim-sequence-evidence.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 实体上的动画状态字段（e+0x6C 与 e+0x70-0x73）

| 字段 | 含义 |
|---|---|
| e[0x6C] | 条目指针数组基址（ROM，127E4 按库号装入） |
| e[0x3C] | 第二资源指针（127E4 常规分支同装） |
| e[0x70] | 当前序列号（04B3C 写入） |
| e[0x71] | 帧位（半字流索引） |
| e[0x72] | 帧倒计时 |
| e[0x73] | 循环模式（0=单次, 1-4=各类循环/保持） |

**互证**：e[0x73] 正是 type0 fn[2] 报告中"e[0x73] 门"的那个字节——
该门禁 = 动画循环模式判断，两线交叉确认。

## 0x08004B3C(序列选择)

```
04B3C(e+0x6C, seq):
  e[0x70] = seq & 0xFF
  e[0x71] = 0                       ; 帧位归零
  stream = e[0x6C][seq]             ; 二级指针: 数组[seq] → 半字流
  e[0x72] = stream[1] + 1           ; 首帧倒计时(首半字高字节)
  mode: (s8)stream[3] >= 0 → 0(单次)
        < 0 → 按倒计时报符号细分 1/2/3/4
```

## 0x08004B9C(每帧步进)

```
e[0x72]-- → 非零直接返回(模式分支)
归零: e[0x71]++ 前进; 读当前半字高字节:
  0xFF(-1): 保持 —— 帧位回退, 倒计时=1, 模式=3
  0xFE(-2): 跳转 —— 帧位 = 半字低字节, 按模式重判
  0x00-0x7F: 正常帧 —— 倒计时 = 高字节, 帧位++
  模式再判定依赖 (s8)条目[3] 与新倒计时符号
```

## 条目（半字流）格式

`(时长 << 8) | 帧号`，时长字节 0xFF=保持、0xFE=跳转（低字节=目标帧位）。

**实例（库 0 序列 0，0x0842EC18）**：`0x0200 0x0201 0x0402 0x0403 0x0404 0xFF00 …`
= 帧 0-1 各 2 帧、帧 2-4 各 4 帧、然后保持——帧号跨条目连续
（序列 1 起始于帧 5），即**一个库共享一套帧编号，各序列是帧流的切片**。

## 完整资源链（闭环）

```
实体类型 → 生命周期/相位处理器 → 127E4(id=(库<<8)|序号)
  → 库号 → 0x0842E800/0x084C9800/0x08414B00[库] → 序列指针数组
  → 04B3C(序号) → e[0x70-0x73] 动画状态
  → 04B9C 每帧步进 → 帧号 → (127E4 尾部合成的 e+0x48/0x49 索引) → 对象帧/OAM
```

## 附加发现

- **库 0x93 与 0x94 共享同一序列数组**（0x08432618）——相邻类型库共享帧数据、
  仅 RAM 表合成参数不同，与"共享前缀=相邻类型"的脚本分布一致；
- 库 0xA6 的数组含非指针交替字（0xFF000100）——存在格式变体，开放。
