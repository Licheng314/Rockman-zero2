本轮深化现有21个研究单元，不新增项目模块计数。状态17与[创建状态16](semantic-attachment-parent-phases.md)共用57820退出选择，但已展开的九个阶段直接调用AC60C/B61B4等接口，没有直接调用类型1F附着对象工厂A20A4。这里仅比较直接调用，不据此断言间接调用树绝不会创建附着对象，也不预先赋予具体敌人或招式名称。

证据来自原始美版ROM，SHA1为c4d93a58f0f82c526dec8a3fdbda170336303689。[原始指令、常量及分派表](semantic-data/parent-motion-cycle-evidence.json)保存11个函数共1163条局部可达指令。55D84通过P+E选择0833C6A0表；本轮确认索引0～8，不把表后相邻数据继续算作该状态。

## 移动参数与边界

P+B8提供水平范围基准，P+BC提供Y基线。阶段2横向使用P+5C旧速度：X+=s8(P+D8)*旧速度，然后速度增加0A，按有符号比较封顶600。左侧限制为B8+1400，右侧为B8+BBFF（对应检查X+1400>=B8+CFFF）。第一次横向触边时竖速设0；后续轮次则继承当前横速，随后P+D9置FF，进入向上的竖向积分。

阶段2竖向使用P+60旧速度，Y+=s8(P+D9)*旧速度，再加0A并封顶600。P+DC累计使用过的旧速度；P+E0记录上次间隔生成位置。当DC>=E0+1000时请求AC60C(3,位置)，随后E0=DC。本轮未展开AC60C内部，保留接口层语义。

阶段4依据D8把X放到另一侧边界，向下使用旧竖速积分、再加0A封顶600。Y+1400>=BC时夹到BC-1400，转阶段2，并把更新后的竖速写回水平速度P+5C。它复用阶段2而非重新执行阶段0，已选额度得以保留。

阶段8只在入口复制全局目标X，夹在[B8+1400,B8+BBFF]；没有在每次下落时继续追踪X。Y初始化为BC-D000，即基线以上208像素；竖速240，每次先积分，再增加40并封顶700。触底夹到BC-1400，转阶段5。该阶段自身没有调用128D4动画推进，不能套用其他阶段的通用假设。

## 旋转反馈与生成接口的边界

阶段2/4把DC用于角度反馈：z=wrap32(368*DC)，其中368为十进制（0x170）；若z为负则先加FF；q=u8(ASR16(z))；P+24=u8(~q)。以u8(2*q)与旧P+12比较，发生回绕时请求声音3C，随后总会更新P+12。负值校正量确为FF，不能按常见除法习惯改成FFFF；P+12在阶段3/7又是计时器，字段名称必须限定阶段。

57A70构造坐标(X,BC-8000)，读取02001000+1D0的低7位；值为7时调用0E964，否则调用11768，返回结果低8位。本轮不把该外部条件命名为容量、可见性或地形检查。满足条件时部分阶段请求B61B4(P,位置,1,0)：阶段2/4为5～8次，阶段8为7～8次，阶段5为6～8次，各自坐标分布不同。

阶段5不论此条件是否成立，还固定提出8次B61B4请求：r2=0，r3依次00/20/40/60/80/A0/C0/E0，位置参数指向P+54，首个栈参数为P.Y+1000。生成请求数不等于成功分配数量；本轮未执行B61B4内部，也不把r3未经验证命名为角度。
