## 主扩展机入场相位（槽 10 = 0x08084729）全解

```
首帧:
  127E4(e, 0x7200)                 ; ★ 脚本库 0x72（19 脚本最大组）!
  0x08006E08(e+0x74, 0x083412D0)   ; 装碰撞描述符 —— 碰撞激活
  e[0xB9] = 0; e[0x12] = 0         ; 计时清零
每帧: 128D4; e[0x12]++ & 0x3F 门   ; 64 帧节奏门
```

**库 0x72 = 类型 0x36 的动画库**——脚本前缀图最大组（19 脚本）的宿主确定。
碰撞描述符 0x083412D0 位于该类型相位数组（0x08341220）附近 = 类型专属数据区。

## 32 处理器结构特征

- 连续银行 0x08084729-0x08085EC9（~0x17A0）；
- **14/32 处理器引用属主 e[0x28]**（0x60 窗口径）——属主驱动行为占近半；
- 无一处理器在前 0x60 内调用 127E4/工厂/B61B4——主扩展机以紧凑运动学/
  状态推进为主（脚本切换集中在入场相位与更深处）；
- 大小分布均匀（单相位 ~0x50-0x90B），典型每相位一动作的演出机。
