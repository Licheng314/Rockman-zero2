# 0x080127E4 图形库切换器：脚本 id 前缀的引擎级语义（类型→资源链收口）

承接 [入口 0 资源普查](semantic-type-e0-resources.md)。本轮解码 127E4 本体，
**脚本 id 高字节（前缀）= 图形/动画库号**由引擎代码直接实证——前缀不是命名约定，
而是资源表索引。证据 = [script-bank-switch-check.py](semantic-data/script-bank-switch-check.py)
（10/10 通过）+ [script-bank-switch-evidence.json](semantic-data/script-bank-switch-evidence.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 127E4(e, id) 全解

```
bank = (id >> 8) & 0xFF          ; 前缀字节
low  = id & 0xFF                 ; 序号(尾部传给 0x08004B3C)
if bank == e[0x1E]: goto tail    ; 同库缓存跳过
if e[0xB] & 4:                   ; 分支 A(标志位 2)
    e[0x6C] = 0x084C9800[bank]   ; ROM 指针表 → 帧配置块
    e[0x1F] = 0xFF
else:                            ; 常规分支
    e[0x6C] = 0x0842E800[bank]   ; ROM 指针表 → 资源块
    e[0x3C] = 0x08414B00[bank]   ; ROM 指针表 → 第二资源块
e[0x1E] = bank                   ; 当前库缓存写回
tail:
if !(e[0xB] & 4):
    e[0x48]10位 = (u16[0x0202E590 + bank*2] + e[0x20]) & 0x3FF
    if !(e[0xB] & 0x20):
        e[0x49]高4位 = u8[0x0202E390 + bank*2 + e[0x22]]
        e[0x23] = 同值
bl 0x08004B3C(e+0x6C, low)       ; 库内切换(序号参数)
```

三张 ROM 指针表（0x0842E800/0x084C9800/0x08414B00）前 8 项均为合法 ROM 指针
（指向 0x08414xxx-0x084C9xxx 的资源块）；两张 RAM 表（0x0202E590 半字基址表、
0x0202E390 字节表）与实体本地偏移 e[0x20]/e[0x22] 合成对象帧索引
（e+0x48 低 10 位 + e+0x49 高 4 位）——**与单元 15"对象帧与 OAM 提交"对接**。

## 类型→资源链最终形态

```
实体类型 e[9]
  └─ 生命周期表 0x08345998[type] → 入口0/相位处理器
       └─ 127E4(e, id):  id = (库号<<8) | 序号
            ├─ 库号 → 0x0842E800/0x084C9800/0x08414B00[库] → 资源块指针
            ├─ RAM 表 + e[0x20]/e[0x22] → 对象帧索引(e+0x48/0x49)
            └─ 0x08004B3C(资源块, 序号) → 库内帧/动作
```

## 二轮修正：入口 0 "表指针参数"的真相

上轮 16 处"0x8345xxx 表指针参数"实为**脚本 id 查找表**——调用点形态为
`ldr r1,=表基址; ldrh r1,[表+idx*2]`（按变体/形态索引），提取器把表基址误记为参数。
已附表内容：类型 2 = [0x8,0x12,0x17,0x18]、类型 3 = [0x5,0x1A,0x1B,0x0]、
类型 13 = [0x14,0x13,0x13,0x0]——即**每类型一张按形态索引的 init 脚本 id 数组**，
嵌入生命周期代码区。type-e0-script-map.json 已更新归因。

## 意义

1. 脚本编码 `(库号<<8)|序号` 三重实证闭环：脚本前缀分布统计 →
   类型族相关性 → **引擎查表行为**；
2. 61 个前缀 = 61 个图形库；43 专属库 ↔ 43 专属类型的资源独立性；
3. e[0x1E] 缓存避免重复装库——库切换有成本的设计证据。
