## 链结构（锚点式双向链表 + 空闲栈）

```
池头: { +0xA(h) 空闲计数 | +0x10 空链头 | +0x14 活动链锚 }
节点: { +0 next | +4 prev }（活动链）+ { +0xA(h)/+0xC/+0x10 }（分配时清零）
```

- **分配 0x08006B84(pool)**：空链头弹出（空则返回 0）→ 空闲计数-- → 头插活动链锚
  （node.prev=锚、node.next=原头、原头.prev=node、锚=node）→ 清 node 0xA/0xC/0x10；
- **变体**：0x08006BF0（固定池 *[0x0200001C]，×16）、0x08006BB8（分配+插入指定节点后，×1）；
- **回收 0x08006C28(node)**：双向摘除（next.prev=prev、prev.next=next）→ 压回
  [pool+0x10] 头插 + 空闲计数++——池 = ***[0x0200001C] 全局切换格***；
  **0x08006C4C(pool, node)** = 池参数化回收变体。

## 调度语义

- **无活动链遍历顺序翻转**：分配头插 + 回收任意位摘除——活动链 = LIFO-ish 但
  回收保持链序，遍历序稳定为"分配序"（与 0x030032E0 碰撞登记的"同桶后登记先
  遍历"形成对照：碰撞桶是真 LIFO，对象池是稳定序）；
- **延迟回收**（单元 11 已解）即"从活动链摘除推迟到退役路径"——本轮回收函数
  证实摘除与空链回压在同一原子操作内完成；
- 开放：[0x0200001C] 全局切换格的切换者（池上下文切换 = 场景切换侧）；九池的
  空链初始化者；0x08006C28（全局池）与句柄池分配的一致性。
