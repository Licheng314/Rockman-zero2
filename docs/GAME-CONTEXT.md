# 游戏背景与改版需求

2026-11-01，来源为项目所有者的说明。用于确定研究优先级；游戏术语与ROM地址的对应仍须用本工程美版GBA基线验证，不能把攻略描述当作反汇编证据。

## 游戏与流程

《洛克人Zero 2 / Mega Man Zero 2》：2D像素动作、战斗、闯关和平台跳跃。用户概述的主线为序章→第一组四个可选任务→过渡任务→第二组四个可选任务→最终连续关卡与最终Boss。每关包含场景切换、杂兵/小Boss及末尾Boss。

其他系统包括基地探索、NPC对话、剧情事件、过场插图、存档和读档。当前只保留流程轮廓，不据此建立全部关卡和Boss的研究任务。

## 主人公与成长

- 武器：剑、枪、盾、锁链；后续代码命名需核对Z-Saber、Buster Shot、Shield Boomerang、Chain Rod。
- 动作：移动、跳跃、战斗、连段、蓄力与组合输入技。
- 属性芯片：改变适用攻击的属性；用户提供的克制关系为火→冰→电→火，具体倍率、适用攻击及例外待代码验证。
- 电子精灵：获得、使用和额外加成；回血罐及菜单回血也属于用户关心的改版方向。
- EX技能：用户描述为与评分、Boss奖励及组合输入有关。不能一概命名为“EX剑技”，需逐武器核对；评分检查发生的时点尚需ROM证据。
- 武器成长、形态、难度会影响动作和能力，初期采用固定装备/形态/难度，避免同时展开全部组合。

## 难度与版本待核对

用户记忆包括简单、普通及解锁困难。当前基线是美版GBA ROM，不把合集的模式、辅助功能或其他版本规则直接套用；模式枚举、解锁条件和实际差异后续按需要验证。此项不阻塞普通难度下的第一阶段。

## 修改需求优先级

1. 主人公能力和属性：可控地修改移动/战斗参数，理解生效与保存边界。
2. 贴图和画面表现：正确导出、替换、回写并在游戏中看到结果。
3. 只在前两类修改需要时追踪存档、奖励、评分或场景交接。

全关卡解说、全部敌人AI、完整剧情翻译、全资源解包均不属于初期目标。阶段与停止条件见[有限语义路线](SEMANTIC-ROADMAP.md)。
