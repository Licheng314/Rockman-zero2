# 0x08012ACC 帧号助手与变体→弹道映射固化

承接 [FF94 弹道族](semantic-ff94-projectile-family.md)。本轮解码 0x08012ACC
并固化变体→弹道映射。证据 =
[acc12-trajectory-evidence.json](semantic-data/acc12-trajectory-evidence.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 0x08012ACC = 帧号提取 + 动态资源变体切换

```
12ACC(e):
  entry = e[0x6C][e[0x70]]           ; 序列条目
  S[0x1A] = entry[帧位] 高字节相关    ; 帧号 → 绘制记录(+34+0x1A)
  if e[0xB] & 4:                     ; 动态资源路径
    帧头表 = 0x084AD300[e[0x1E]]      ; 动态 bank 帧头表
    if S[8] != 帧头表: S[0x3C] = 帧头表
    variant = 帧头[帧号].b3           ; 帧头第 4 字节 = 资源变体
    if e[0x1F] != variant:            ; 变体缓存
      e[0x1F] = variant
      → 0x0202E790[variant*2] 参数 → 图块/调色板请求
```

**与单元 15 精确互证**：S+0x1A 帧号写入、0x084AD300 动态帧头表、帧头第 4 字节
资源变体——单元 15 的消费侧描述在实现级全部落实。**128D4 = 04B9C（帧步进）+
内联同款帧号提取**；0x08012ACC 为独立共享变体（不步进、只刷新帧号/资源的
调用方使用）。

## 变体→FF94 弹道映射（固化）

子状态 9 分派器（0x08079F89）按 `FF94[e[0x10]]` **直索引**——变体号 = 弹道号：

| 变体 | 弹道 |
|---|---|
| 0 | 命中体（e[0x8C]&0x200 → 爆炸） |
| 1/2 | 计数体（owner[0xCC]--） |
| 3 | 持续弹幕 |
| 4 | 重力下落 |
| 5 | 水平冲刺 |
| 6 | 纯重力下落 |
| 7 | 队形跟随 |
| 8 | 定时折返 |
| 9 | 碰撞引信 |
| 10/11 | NULL（无弹道——与一次性变体自洽） |

**类型 0x21 的 e[0x10] 变体号 = 攻击弹道号**——生成侧（0x080AC60C 邻域工厂）
写入的变体参数直接决定弹体行为。类型 0x21 解码至此完整：
28 相位 + FF38/FF60/FF70/FF94/FFA0 五分派表 + 弹道族 + 工厂。
