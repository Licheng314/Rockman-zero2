# 动态矩形快照轮换与暂停语义

日期：2026-10-29。深化第20个动态碰撞单元，补齐此前未定位的历史列表维护入口，不增加模块计数。仅只读已有汇编与原ROM，并更新独立研究资料。

[原始指令位置、复制参数与状态示例](semantic-data/rectangle-history-evidence.json)。基线SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。示例为静态推导，不是实时RAM抓取。

## 入口在14AD8，不在矩形登记器

14AD8保存参数的低8位skip。08014BA2读取它，非零直接跳08014C1E；为0才进入摄像机更新、矩形快照、地图状态更新和震动生成路径。

此前只沿099BC登记器及其实体调用者寻找，缺失的是这里的场景显示/摄像机流程。新定位的08014BB2从常量池08014C5C读取020011D4当前数组基址；目的地址为其+300，即020014D4历史数组。

## 复制有效前缀，再提交计数

currentCount=u8[020011D2]。有效字节数B=currentCount*24，复制仅针对活动前缀，不先清整张历史数组。

- 先把B向下对齐到32B，按32位字数调用EEF68/CpuFastSet。
- 若B&31非0，再用EEF6C/CpuSet的32位模式复制末尾8/16/24B。
- 08014BF8读取原currentCount，08014BFC将它写到020011D3，即historyCount。
- 08014C04把已验证为0的skip字节写020011D2，清currentCount。

| 活动项数 | B字节 | 快速部分参数对应字节 | 尾部字节 |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 1 | 24 | 0 | 24 |
| 2 | 48 | 32 | 16 |
| 3 | 72 | 64 | 8 |
| 4 | 96 | 96 | 0 |
| 31 | 744 | 736 | 8 |

数值按十进制。CpuFastSet调用没有因快速计数0而在本函数内被跳过；本报告只确认传参和活动计数语义，不模拟BIOS的零计数边缘行为。历史数组中超出historyCount的残留字节不属于活动列表，不能仅凭看到旧记录就认为对象仍有效。

本轮登记结束后的当前坐标，成为下一轮登记按id查找的历史坐标。不是交换两个指针，而是从固定当前区复制到固定历史区，然后把当前计数清0。

## 在主更新中的位置

常规E4390路径先执行若干对象池12034回调/登记，之后在080E4764调用14AD8。它传入：

```text
skip = pending || (进入E4390时读取的0202E144快照 != 0)
```

pending的来源及实体/恢复不同门控见[状态门控报告](semantic-runtime-gates.md)。这里使用的是本轮入口保存的E144，而非在14AD8调用前重新读取全局值。

当skip=0，本轮矩形登记结果才成为历史；skip非0时不复制、不更新historyCount，也不清currentCount。模式表中的E4924和E4A5C两个调用者都显式传1，因此这些状态的14AD8调用保持原列表。

skip非0也不表示整个函数立即返回：14C1E之后还可处理绘制队列、场景辅助显示并执行14F9C。因此“画面仍在提交”与“动态碰撞快照继续轮换”必须分开。

## 历史坐标的准确含义

历史记录是最近一次skip=0快照保存的坐标，不保证来自上一个显示帧，也不保证来自上一次14AD8调用。冻结或状态过渡期间可能连续多次skip=1，历史值保持不变。

一个只含id7的例子（x按整数像素展示，实际记录为定点；假设快照后没有其他地图/对象回调再登记，空列表指计数提交瞬间）：

| 事件 | 当前列表 | 历史列表 | 新登记记录中的dx |
|---|---|---|---|
| 首次登记x100 | [x100] | [] | 0（未匹配历史，取自身位置） |
| 14AD8(0) | [] | [x100] | 不新增登记 |
| 登记x103 | [x103] | [x100] | 3 |
| 14AD8(1) | [x103] | [x100] | 保持3 |
| 14AD8(0) | [] | [x103] | 不新增登记 |
| 再登记x103 | [x103] | [x103] | 0 |

1F478等贴附函数按记录内当前/历史差带动实体，因此在有暂停时，差值不是固定每帧速度；不能直接除以一个屏幕周期当作可靠运动速度。

计数清0之后，14AD8还可能调用08080B8及地图/层回调；这些路径可进入099BC，不能保证14AD8返回时currentCount仍为0。清零表示新登记轮次开始，而非整个函数返回后的空表保证。实际例子：地图索引2的层回调表08315340在08315370保存0800B479指针；选中对应层配置时，B478会调用099BC。

当前列表在skip=1时也被保留。E4390对对象更新另有多层门控，不能未经检查就假设所有登记器此时都停了，或反过来假设每帧必追加重复项。已知099BC不去重、当前最多31项，这些约束仍需与具体对象池/模式共同使用。
