# 类型 0x36 相位→动画/碰撞配对表（全量提取）

承接 [逐相位碰撞目录](semantic-type36-phase-collision-catalog.md)。本轮程序化
提取全部 42 槽的 127E4 脚本参数与 0x08006E08 描述符参数。数据 =
[type36-phase-pairing.json](semantic-data/type36-phase-pairing.json)（全量表）。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 提取方法

全 42 槽处理器（银行连续域分界）线性扫描：`bl 0x080127E4` 回溯 r1
（含 `movs #imm; lsls` 移位链折叠——0xE4<<7=0x7200）；`bl 0x08006E08/DE4`
回溯 r1 描述符指针。结果：**32/42 相位含脚本、13/42 含描述符**。

## 配对表要点

**动画序列（库 0x72 为主，启动组用库 0x62）**：

| 序列 | 使用相位 |
|---|---|
| **0x6201** | 槽 0（init，库 **0x62**!） |
| 0x7200 | 槽 5/10/11/13/14（基础待机/移动，×6） |
| 0x7201-0x7202 | 槽 15/16（攻击起手） |
| 0x7203 | 槽 12/20/28（×3 复用） |
| 0x7204-0x720C | 槽 17-26（各攻击动作一一对应） |
| 0x720D | 槽 27/29/35/37（×4 复用——受击/通用） |
| 0x720E-0x7212 | 槽 30-41（收尾族） |
| 0x721C | 槽 34（特殊） |

**碰撞描述符**：0x083412D0（基础，×5）/ 0x08341300（×2）/ 0x08341330（×3，
冲刺族）/ 0x08341360+0x08341330（槽 27 **双装**）/ 0x08341390（槽 38）；
exit 槽（3/8）装 0x0833DB44 = 共享拆除族描述符。

## 结构定论

1. **动画序列与相位一一对应**（0x7204-0x720C 段每序列恰一相位）——
   库 0x72 的 19 脚本即主扩展机各动作；序列复用（0x7200/03/0D）= 多相位
   共用动画；
2. **init 用库 0x62**——脚本前缀 ≠ 实体类型号（0x36 型用 0x62/0x72 库），
   库分配按"资源族"而非类型（修正前缀图推论"0x72→类型 0x37"为
   "0x72→类型 0x36 动画库"）；
3. 描述符 6 种 + 复用模式 = Boss 各招式独立判定盒的完整目录。
