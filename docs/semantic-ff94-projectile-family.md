## 结构解读

FF94 = 变体 1 子状态 9 的**弹道选择表**——e[0x10]（变体）选弹道：
弹幕压制(3) / 抛物下落(4/6) / 冲刺(5) / 护卫跟随(7) / 折返巡逻(8) / 触发引信(9)。
两个脚本 id 分工：**0x3701 = 攻击通用动画、0x3700 = 冲刺/折返动画**——
与脚本前缀 0x37 的类型族编码一致（0x37 → 相邻类型族）。
