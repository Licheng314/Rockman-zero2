# 动态接触的水平线段余量查询

2026-10-29。深化已有地图/地形及动态矩形研究，累计仍20单元。读取212DC、20E04、20D28及EF150原ROM可达分支，保存[指令、调用与字面常数证据](semantic-data/horizontal-clearance-evidence.json)。仅独立语义研究，不写正式源码、段清单或后台状态。基线SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

地址与字段偏移为十六进制；公式数值使用0x前缀。坐标24.8，结果基于静态指令，不是游戏运行观测。212DC可暂称“线段余量查询”，不将它命名为通用矩形可通行测试。

## 五参数接口及静态地形修正

212DC(L,R,T,B,skipIndex)先计算w=R-L、h=B-T。第五参数在push32B及局部4B之后由[sp+0x24]读取，是动态列表索引，不是记录的id。

若初始w>0：

```text
L += 0930C(L,T)  // 向正X推出，静态地形
R += 09190(R,T)  // 向负X推出，静态地形
w = max(R-L,0)
```

两个入口都不带动态矩形补查，但保留8000位过滤、最多16次跨格及耗尽±1的特殊返回。此函数直接把结果加到端点，未为耗尽另加错误处理；不能假定一定得到经过证明的通行区间。

初始w<=0时跳过上述修正，未统一把负宽度归零；h从头到尾不改变。任一路径最终返回严格等价于：

```text
(w > 0 || h > 0) ? 1 : 0
```

因此只要初始B>T，最终就为1，哪怕宽度已耗尽。原程序的实际调用上下文才使其成为有用的水平判定，不能凭四个坐标参数宣称支持完整二维可通行检测。

## 动态列表倒序裁剪

读取当前计数020011D2，从最后一项到第一项扫描，24B步长。跳过索引等于skipIndex的项，并跳过attribute&0x8000非零项。这里与部分首次命中点查询的正序不同。

矩形字段沿用当前中心cx/cy及u16半宽hw、半高hh。令a=cx-hw，b=cx+hw-1。先检查：

```text
u32(L - (a-w)) < w + 2*hw
u32(T - ((cy+1-hh)-h)) < h + 2*hh
```

两项比较右侧也按32位机器算术；不用连续几何重写等号。h=0时，纵向即T处于(cy-hh,cy+hh]的离散点包含范围。

若命中但w<=0，不修改。w>0时还要求：

```text
L >= a 或 b >= R
```

若L<a且b<R，即矩形完全处于两端之间，直接跳过，不将区间拆成两段。满足要求后依序执行：

```text
若 L < b：L = b+1
若 a < R：R = a-1
w = max(R-L,0)
```

比较确为L<b，不是L<=b；两次赋值都可能发生，不能简化成选左边或右边保留较宽区间。扫描不重启，列表顺序和先前端点修改会影响后续条件。

以下为十进制静态例子，假定静态地形修正均为0、h=0且纵向包含成立：

- L=0、R=100，矩形a=40、b=59：内部障碍被跳过，返回1。
- L=0、R=100，矩形a=-10、b=109：依序得L=110、R=-11，w=0，返回0。

第一例说明返回1不能解释为“整段没有任何障碍”。这套逻辑服务于具体接触候选的可用范围，不是寻找所有空白区间或最大间隙。

## 20E04如何传入零高度线段

20E04有8个参数，暂按输入角色命名为(A,B,shapeA,shapeB,C,halfWidthPtr,flag,index)。A/B/C为坐标指针，命名只用于对应参数，未凭本函数断言它们一定属于前/后哪一屏幕帧。shapeA/B的+4读u16纵向边缘偏移，halfWidthPtr首32位字参与水平半宽。

对index项读取当前和历史中心：

```text
Q = B.y + u16(shapeB+4)
P = A.y + u16(shapeA+4)
oldTop = oldCy + 1 - hh
newTop = cy + 1 - hh
```

若Q>=oldTop直接返回0。令relative=(P-Q)-(newTop-oldTop)。relative==0时，flag非零返回0；flag==0跳过插值检查，直接走最终线段检测。非零时进行相对运动交叉位置检查。

最终采用当前矩形横向范围与C的水平范围求交：

```text
L = max(cx-hw, C.x-halfWidth)
R = min(cx+hw-1, C.x+halfWidth)
y = newTop-1 = cy-hh
返回 u8(212DC(L,R,y,y,index))
```

这证实h=0，并明确排除正在检验的动态矩形自身。返回值用于该接触候选，不能脱离上下文赋予全地图路径规划含义。

## 相对运动的交叉位置检查

EF150为有符号整数除法：原始指令先保存分子/分母异号，取绝对值做无符号移位减法求商，末尾按符号取负，通常整数域即向零截断。除数0另调用EF1E4后返回0；20E04正常进入此计算时已排除relative==0。0x80000000极值及乘法溢出仍按原32位机器行为，不泛化为无限精度数学。

设gap=oldTop-Q，dx=A.x-B.x，在通常无溢出域，20E04计算：

```text
sampleX = C.x - (dx - trunc0(dx*gap/relative))
platformX = oldCx + trunc0((cx-oldCx)*gap/relative)
combinedHalfWidth = hw + halfWidth
u32(sampleX-(platformX-combinedHalfWidth)) < 2*combinedHalfWidth
```

不成立则拒绝候选。两次相乘在除法前已经只保留32位，不能改成64位乘除后直接声称二进制语义相同。插值检查之后仍要通过上节静态/动态水平线段查询；它本身不是最后的接触判定。

## 上层20D28：记录候选，不只消费一个bool

20D28转发参数调用20E04，将结果截为u8。若控制参数（该函数入栈参数位置+0x48）非零且查询为0，转交20F28处理；该分支的完整协议本轮未展开。

其余路径把index对应位写入上下文+0x70起的位图，并经1F3D0(context+0x84)查找既有记录索引。若已有索引就是本项，跳过候选替换。否则以当前矩形cy+1-hh比较输出坐标指针的Y：上下文+0x7A为0xFF或本项Y更小时，更新输出Y及+0x7A索引；Y相同时，比较输入A.x到两个矩形cx的距离平方，较近者替换索引。

平方在32位内运算，比较为有符号，不能不加条件地把所有可能输入概括成欧氏最近距离。位图写入还包括控制参数为0时查询结果为0的路径，不能命名为“所有通过碰撞检测的接触集合”。+0x7A是列表索引，不是矩形id；与+0x84经id检索出的索引需区分。
