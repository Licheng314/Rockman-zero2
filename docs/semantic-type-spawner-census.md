# 类型生成点普查：只保留搜索线索

2026-11-01审计替换重复且互相矛盾的旧稿。原文、原始搜索数据与Git历史保留；搜索命中数不是已验证工厂数或语义覆盖率。

原始 [生成点搜索](semantic-data/spawner-type-writes.json) 报告334个写入候选、80种字节值，可作定位索引；回溯窗口会跨基本块，结果需要逐点核实。不同池内相同类型值不能合并为同一种实体。

旧稿把0x080B6094改判为“不是类型写入”有误：它是0x080B6070工厂内部的类型0x22写入。0x080A3628也是内部写入点，工厂入口为0x080A35FC。它们分别属于0x0202F084、0x0202F07C池，不能直接当作0x0202F078池内0x22的生成工厂。

六个已执行验证的工厂、调用签名及生命周期见 [池作用域报告](semantic-entity-type-scope.md)。后续只按“池句柄＋类型表＋类型值”逐点回验，不沿用旧稿的角色身份猜测。
