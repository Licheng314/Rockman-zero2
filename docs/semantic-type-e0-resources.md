# 类型→资源映射第一层：生命周期入口 0 的脚本引用全普查

承接 [脚本 id 编码规律](semantic-parent-lifecycle-dispatch.md)（附2）与
[类型普查](semantic-data/type-census.json)。本轮对 75 个生命周期类型的**入口 0（init）**
做确定性空间窗口（相邻入口 0 之间）线性扫描，提取 127E4 脚本切换调用及其参数。
**修正早前"入口 0 不含 127E4 调用"的结论**（该扫描有缺陷，实际 init 区域共
142 处 127E4 调用）。数据 = [type-e0-script-map.json](semantic-data/type-e0-script-map.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 方法

- 窗口 = [入口0, 下一类型入口0)（确定性空间分界，无函数边界启发式）；
- 每处 `bl 0x080127E4` 回溯 ≤14 条找 r1 来源（字面量池/movs 立即数）；
- 产物按 id 类别分箱。

## 三类 id 参数（142 处）

| 类别 | 例 | 解释 |
|---|---|---|
| 0x02-0x17 小 id | 类型 1: 0xD/0xC；类型 5: 0xB/2/0x11/0xD | 通用动作脚本（跨类型共用，与脚本前缀图的"前缀 0x00 通用"衔接） |
| 0xNNxx 族前缀 | 类型 9: 0x9305；类型 10: 0x9407；类型 11: 0x9504/0x950A | **前缀 ≈ 类型号×0x10**（9→0x93、10→0x94、11→0x95）——脚本 id 高字节即类型族编码的又一实证 |
| 0x8345xxx 指针 | 类型 2: 0x8345B28×2；类型 3: 0x8345B44；类型 13: 0x8345D50 | 127E4 的**表指针参数**（动态配置，非脚本 id）——16 处，指向 0x083459xx/0x08345Dxx 生命周期表区附近 |

## 结构观察

1. **init 双形态**：
   - 薄型（如类型 0/1/4/5/7）：装 D=1 + e[0x14]=fn[1] + 尾调用共享助手——
     脚本引用在助手中（窗口法可覆盖，归属标注为"init 区域"）；
   - 厚型（类型 2/3 等）：直接携带表指针参数；
2. **脚本序列重复**（类型 1: 0xD,0xC,0xD,0xC；类型 7: 0xE×7）——同一 init
   区域按变体/模式分支重复切换脚本，与变体系统的 e[0x10]/e[0x11] 双参数呼应；
3. 与 [type-script-map.json](semantic-data/type-script-map.json)（相位处理器侧
   351 id）合并后，类型→脚本映射覆盖 **init + 相位两层**。

## 表指针参数的目标域

0x8345B28/0x8345B44/0x8345D50 落在 0x08345998 生命周期表区 +0x190-0x3B8 偏移——
即 init 把**同族其他类型的生命周期指针**传给 127E4（跨类型行为绑定或形态切换表）。
精确语义待 0x080127E4 本体解码。
