## 第二层分派架构：分派表家族扩至 7 张

变体 1 内部各子状态再按 e[0x10]（变体号）分派：

| 表 | 用途 | 有效项 |
|---|---|---|
| 0x0833FF38 | 子状态跳表（e[0xD]，12 目） | 0-7/10/11（8/9=共享退出/退役） |
| **0x0833FF60** | 子状态 5 → 按 e[0x10] | 0-10，[11]=0x08065A05 |
| **0x0833FF70** | 子状态 6（模式 0）→ 按 e[0x10] | 0-9；**= FF60 右移 4 项的别名** + 独有尾（8=退役） |
| **0x0833FF94** | 子状态 9 → 按 e[0x10] | 0-9；**[10] = NULL——变体 10/11（一次性生成）无攻击行为，自洽** |
| **0x0833FFA0** | body11 内部按 e[0xD] | 0-6；**= FF94[3..9] 的别名**——同一批本体双入口 |

## 本体银行语义图（0x08079870-0x0807A5xx）

### 攻击初始化体 0-3（0x08079871/98D9/9941/99A9，仅脚本 id 不同）

```
12580(动画初始化) → 127D0 → A |= 1|2 → 127E4(e, 脚本id) →
e[0x49] = (e[0x49] & ~0xD) | 4 → e[0xB] |= 0x10 → e[0x1D] = owner[0x1C] →
D=1, e[0x14]=fn[1] → bl 子状态6(0x08079810)
```

脚本 id：**0xA50E / 0xA50F / 0xA520 / 0xA506**——与 [脚本前缀映射](semantic-parent-lifecycle-dispatch.md)
的"前缀 0xA5 = 0x20 族"互证（4 个攻击脚本序号不连续，与变体号无直接对应）。

### 贴位体 4-6（0x08079A5D/9AD5/9B4D，三者几乎同构）

门禁：属主相位≤1 且属主 D==5，否则 D=2+fn[2]+拆除块（转退役）。通过则：
0x08012A14(e) → 镜像属主朝向（e[0x4C]/e[0x4A] 位4）→ **拷贝属主坐标到 e[0x54/58]**。

### 飞行体 7（0x08079BC5）：54+=5C、5C+=64（x 加速飞行），5C 归零转子状态 1；
属主相位==4 时转 D=2+拆除块。

### 攻击主处理器 body8（0x08079C7D，0x30C 字节）

D=1+fn[1] 装载后按 e[0x10] 三分支（0/1/2），公共骨架：

```
朝向全局目标(0x0202E130 指针, target.x < e.x 定朝向) → A |= 4
0x08006DE4(e+0x74, 0x0833FFC4, &e[0x54], 2 或 0x12)   ; 附属安装(另一安装器!)
LCG 随机(见下) → 次数 2-3 → 循环 0x080B61B4(0, {x, y+0x1800}, 1, 0)  ; 类型0x23生成
127E4(e, 0x3701)                                       ; 攻击脚本
变体2 附加: 0x08012CA4(e, 7)
尾: 12580 → bl 子状态9分派(0x08079F88 → 0x0833FF94[e[0x10]])
```

分支差异：变体 0 先 Y 落地调整（0x080093C4）；变体 1/2 装附属后清 B4。

### 爆炸体 body10（0x08079FA1）

音效 **0x2A**（0x080032EC）→ LCG 两次取随机 → 坐标 = 自身 + ((rand&7)-3)<<8, -0x700+(rand&7)<<8
→ **工厂 0x080AC60C(2, 坐标)** 散布产物；e[0x10]==0 时 0x0801DD2C(0, &e[0x54])。

### 命中体 body11（0x0807A075 = FF94[0]）

- 门：`e[0x8C] & 0x200`（被击中标志）→ D=2 + fn[2] + 清 8C/90/94 + A&=~4 + **bl body10（爆炸）**；
- 否则：谓词 **0x08065A24**（C 集成 #4，已知）→ `e[0x8C]&1` 时
  e[0x2C] = 0x0801E11C(0, e, 0x0833FFBC)、e[0xB8] = 旧 e[0xD]、**e[0xD] = 6** →
  按 0x0833FFA0[e[0xD]] 子分派。

### 计数体 body12（0x0807A129 = FF94[1]/[2]）

e[0x8C]&0x200 或无属主 → D=2 路径；否则 **owner[0xCC]--**（属主上的计数递减）→ D=2。

## 类型 0x22 生成工厂 0x08079C14（全签名）

```
spawn_type22(owner, *coords, variant, mode):
    node = 06B84(池 0x0202F078); if 0: return 0
    node[0x25] = 0x18
    node[0x9]  = 0x22
    node[0x14] = 0x0833D990[0x22]->fn[0]     ; 偏移 0x88 = 0x22*4——按类型索引!
    node[0x20h] = 0; node[0x22] = 0
    node[0xB] |= 0x10
    node[0x1D] = node[0x1C]
    node[0x28] = owner
    node[0x54/58] = coords[0]/coords[1]
    node[0x10] = variant                     ; ★ 变体参数直传
    node[0x11] = mode                        ; ★ 模式参数直传
    return node
```

**修正**：此工厂即[生成工厂 1](semantic-type22-spawners.md)（尾 0x08079C3E）——
参数完整后可见**类型 0x22 与类型 0x20 一样具有 e[0x10] 变体 / e[0x11] 模式双参数体系**，
两族实体共享同一"变体×模式"配置模型。池基址 0x0202F078 与工厂 0x080AC60C 的
0x0202F084 相邻（两个池）。

## 全局 LCG 随机数发生器（新识别）

```
state @0x0202E188:  state = (state * 0x343FD + 0x269EC3) << 1; 用位 16-30
```

glibc 式 LCG，双倍左移后取高位——body8 的生成次数（2-3）与 body10 的散布偏移
均用它。这是全 ROM 级"全局 RNG"的定位。
