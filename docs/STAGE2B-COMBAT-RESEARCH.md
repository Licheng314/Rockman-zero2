## B1：输入→动作状态机与窗口表

玩家帧驱动 0x08023420（入口指针 P+0x14，由出生初始化 0x08023234 写入）：`P+0x0D` 顶层模式（0=常规、5=受击、7=脚本、0xA/0xB=死亡）→ `P+0x0E` 动作状态（0 站立/1 走/2 冲刺/3 空中…）。攻击请求路径：动作前段 0x080236EC（A 跳 > 冲刺 > 走）→ 请求缓冲 **P+0x2BB（攻击码，1 字节）** → 0x08035984 查攻击码表（行=[0x08335B18+4×P+0x1FC]，剑中性 tier0/1/2 = 2/2/1）→ 0x08035ADC 提交（写 +0x178 类、+0x179 段清 0）→ 类分派表 0x08333C6C → 剑段表 0x08333FD4。

**实测规则（无目标基线，逐帧扫描 1-39 帧第二按）**：

| 按键时机（第一斩 0 帧起） | 结果 |
|---|---|
| 第 1-18 帧（斩击进行中） | 完全忽略，不缓存不接段（单按/连按均如此） |
| 第 19 帧起（斩击结束后任意帧） | 立即接第二段（新按帧即起手） |
| 第三段后再按（第 61 帧起） | 不再接段——**三段上限** |
| 两段后走/跳跃等状态切换 | 连段状态重置，下次按键回第一段 |
| 两段后纯站立等待 | 连段状态保留（不下按则不重置） |

段动画：第一段 pose 42（子相位 1×2帧 → 2×6帧 → 3×10帧），第二段 43（2 段 6 帧），第三段 45/46/47（表 0x08335B40-B7C 的动画号与窗口帧界 +5/+6）。命中时攻击方附加 **命中停顿 ≈4 帧**（有目标时第一段 18→22 帧）。连段命中伤害实测递增：第一段 8、第二段 9、第三段 10（表 0x08335C00 前驱组与段表对应）。

蓄力：`P+0x188` 计数由 0x08037408 每帧累加（要求 +0x212==+0x213 同武器、B 按住、0x08034BB8 判定可蓄）；**任务 1 的剑成长 P+0x223≤2 → 不可蓄**（0x080354FC 返回 -1）；夹具 +0x223=3 后阈值 120 帧档。蓄力仅在开招动画结束后开始计数。释放（0x08036E60）实测需要蓄力计数 ≥ 约 150 帧（143 释放失败、162 成功——与静态阈值 120 不符，**未定**：释放门 0x08036E60 的阈值修正项）。成功释放 → pose 52 + kind-8 攻击实体（描述符 0x08337DC8，伤害 10；更高蓄力档描述符切 0x08337E28）。

升龙（code 5）：**地面 上+B 且 P+0x218 位 0x10**（EX 使能）→ pose 48(8帧)→49(21帧)→50(4帧)，vy 初值 -1088（重力 64/帧），后向漂移 vx -560→0，最高点比站立高 10944 subpixel（≈42.8px，高于普通跳 ≈26.3px），约 46 帧后回落。**空中 上+B = 普通空中斩（pose 59），升龙不能空中发动**。
下戳（code 6）：**下+B 且 P+0x218 位 0x80** → 仅地面版：地面下段突刺 pose 51（24 帧，攻击活跃 ≈20-44 帧）；**空中 下+B = 普通空中斩**——美版 Z2 基础+EX 体系内未发现空中下戳发动方式（静态 code 6 创建器 0x0803B314 存在，空中触发条件**未复现**）。

## B2：三条假设链

实测 HP 时序（耐久 Pantheon 夹具，见 `build/stage2b/combat-fixtures-result.json`）：

1. **三连斩→升龙：成立。** 斩1(-8)→斩2(-8)→升龙(-14)，全程实际扣血。注意三段后连段状态会阻挡下一次普通斩，但升龙（新类别）不受影响。
2. **蓄力斩→三连斩：半成立（蓄力斩重开连段）。** 蓄力斩命中 -10（pose 52）；其后的 B 按键从**第一段**重新开始（-8、-9），不是接第三段。Z3 的 comboLv 体系（saber.c sTripleSlash1/2/3 collisions, comboLv 1-3）在 Z2 由段表 +0x179 承担；蓄力斩与三连斩共享同一请求缓冲但互为独立链。
3. **枪弹→蓄力斩→三连斩→升龙→下戳：两点合法失败。** (a) 点身距（≈7px）枪弹**未碰到目标**：弹丸实体（kind 1，描述符 0x08336138，伤害 2）实际生成于枪口前方 ≈30px（411135 vs 零 403455），越过身侧敌人后消失——输入接受、攻击生成，但命中几何不成立；(b) 下戳链接不可用（空中无下戳，见 B1）。蓄力斩→三连斩→升龙各链接本身按链 1/2 成立。

## B3：升龙短按与长按对照

短按（1 帧上+B）与按住 40 帧的轨迹**逐帧完全一致**（最高点同为 103743，vy 初值 -1088，退出帧一致）：升龙不是蓄力型招式，按住不改变轨迹。退出原因=自身上升结束后受通用重力回落（与通用跳跃同一重力写入路径 64/帧），落地进入恢复 pose 50 后回常规状态；观察窗口内未发生碰顶/受击打断（有界：未构造碰顶场景）。
