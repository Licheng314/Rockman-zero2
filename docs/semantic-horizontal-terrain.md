# 水平方向地形形状响应

本轮深化已有地图/地形研究，累计仍为20个研究单元，不据此推断全项目模块总数。根据原始美版ROM逐分支读取12个助手、解析PC相对常数和两张各16项指针表，补齐此前未展开的水平方向标量公式。原ROM SHA1为c4d93a58f0f82c526dec8a3fdbda170336303689。没有运行游戏、匹配/集成C或修改后台提取。

完整指针、可达指令、常数及含字面池/填充的区间SHA1见[原始证据](semantic-data/horizontal-terrain-evidence.json)。以下地址均省略0800前缀，表地址保留完整值；表中的原始Thumb指针最低位为1，函数地址已清除此位。所有公式常数均为十六进制。

## 参数与消费者

| 表 | 已确认消费者 | u | v | 应用响应 |
|---|---|---|---|---|
| 08312C0C | 090D4、09190 | y&FFF | x&FFF | x+=response |
| 08312C4C | 09240、0930C | y&FFF | (~x)&FFF | x-=response |

解释域为局部整数u,v∈[0,FFF]，坐标单位1/256像素，1000对应16像素。response是有符号位移，不能改成bool；~v=-(v+1)。不将公式泛化到任意32位输入或溢出情形。

## 两组分段公式

为简洁记录，下面用L(s,k)和P(s,k)表示经逐函数归纳的数学形式，不表示原代码必有这两个公共函数。k取2或4，w=1000/k。

L(s,k)为斜线位移：

```text
u < s       : 0
u >= s+w    : ~v
其余        : -max(v + k*(u-s) - 1000, 0)
```

P(s,k)为分段命中后的整格位移：

```text
u < s       : 0
u >= s+w    : ~v
其余        : v < k*(u-s) 时返回 ~v，否则 0
```

两组在u=s处都返回0。在s+w=1000时，第二分支不在有效局部输入域内；这只是统一记法，不声称原函数保留了不可达分支。P的等号边界不命中；L的q=0也返回0。

| 函数 | 公式 | 原指令关键阈值 |
|---|---|---|
| 09DA4 | L(0000,2) | u>07FF整格；否则q=v-1000+2u |
| 09DD4 | L(0800,2) | u<=07FF为空；否则q=v-1000+2(u-0800) |
| 09E08 | L(0000,4) | u>03FF整格；否则q=v-1000+4u |
| 09E38 | L(0400,4) | u<=03FF为空；u>07FF整格；中段算q |
| 09E78 | L(0800,4) | u<=07FF为空；u>0BFF整格；中段算q |
| 09EB8 | L(0C00,4) | u<=0BFF为空；否则q=v-1000+4(u-0C00) |
| 09EEC | P(0800,2) | u<=07FF为空；否则比较v与2(u-0800) |
| 09F14 | P(0000,2) | u>07FF整格；否则比较v与2u |
| 09F34 | P(0C00,4) | u<=0BFF为空；否则比较v与4(u-0C00) |
| 09F5C | P(0800,4) | u<=07FF为空；u>0BFF整格；中段比较 |
| 09F90 | P(0400,4) | u<=03FF为空；u>07FF整格；中段比较 |
| 09FC4 | P(0000,4) | u>03FF整格；否则比较v与4u |

## 边界与整格分支

09DA4在u=07FF、v=0800时，q=07FE，响应=-07FE；u变为0800时进入整格分支，响应=~0800=-0801。若将斜线公式延长至此，只会得到-0800，差一个最小单位（1/256像素）。相邻两个输入的实际响应相差3个单位。不能把整格分支写成斜线的简单限幅。

09F14在u=07FF时，阈值为0FFE：v=0FFE返回0，v=0FFD返回~0FFD=-0FFE。下一分段u=0800则对所有有效v返回~v。以上是静态公式推导示例，不是游戏运行观测。

水平搜索仍保留属性8000位过滤、最多16次跨格、负X耗尽+1/正X耗尽-1等接口规则；090D4/09240还分别补查动态矩形，不能用静态表替代整个查询。相关结构见[动态矩形](semantic-dynamic-rectangles.md)与[快照轮换](semantic-rectangle-history.md)。
