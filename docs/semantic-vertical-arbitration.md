# 静态地形与动态矩形的纵向结果仲裁

2026-10-29。深化已有地形/动态矩形研究，累计仍20单元。补齐1F6AC/1F820的完整结果选择分支，连接前述[属性聚合](semantic-contact-bounds-flags.md)、[四通道分派](semantic-contact-dispatch.md)及[方向回调](semantic-contact-directions.md)。[原ROM证据](semantic-data/vertical-arbitration-evidence.json)记录5个函数的可达指令、常数和区间摘要，基线SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。未运行游戏、改写正式代码或干预后台提取。

以下偏移/地址均十六进制，公式用0x前缀；坐标24.8。T表示静态返回的u16属性/结果，i表示动态u8索引，D=动态记录属性|0x80，S为选中结果，AUX为传给聚合器的辅助结果。不能把S当bool或把返回的u16 S当坐标。

## 两份工作位置分开求解

1F6AC(P,other,C,shape,...)形状指针为空时分别取C首两个指针。输入位置复制两份：Ps交1FE4C求静态结果T，Pd交208D0求动态索引i。两次调用都在栈上工作位置运行，不先把静态修正写回输入，再在该位置做动态求解。

1F820先调用1F2E8对另一份局部坐标做纵向边界检查，随后由该局部坐标再复制Ps/Pd；201F8求静态T，20974求动态i。完整静态采样细节仍在独立入口中，本文不把这些上层仲裁公式替代底层形状查询。

应用参数为0时，包装本身可能不更新工作位置，但上下文/候选仍可变化，且方向回调过滤也受应用参数影响。因此以下无应用路径不能理解成“应用路径最终结果的无副作用预览”。

## 1F6AC：候选Y不同且允许应用时取较小者

AUX初始0；选择规则按实际分支顺序：

| 条件 | S | AUX |
|---|---|---|
| i==FF | T | 0 |
| i!=FF且T==0 | D | 0 |
| 两者都有，apply!=0，Pd.y<Ps.y | D | 0 |
| 两者都有，apply!=0，Pd.y>Ps.y | T | 0 |
| 两者都有，Y相同或apply==0 | 按下节水平规则 | 另一路结果 |

Y用有符号比较。选择较小绝对Y只发生在允许应用且Y不同的分支，不是无条件按最小Y排序。Pd.y==Ps.y时也不按固定“动态优先”。

## 同位或无应用时的水平规则

先检查原输入P.x是否处于动态矩形的横向半开范围，原指令为：

```text
u32(P.x-(cx-hw)) < 2*hw
```

成立则S=D、AUX=T。未成立时取dx=C+30处保存的静态采样X减P.x；s在朝向控制参数非零时+1，否则-1：

```text
dx==0 或 s*dx>0：S=T，AUX=D
否则：S=D，AUX=T
```

C+30是220D8所写的共享采样坐标，不是任意最近地形点；跨方向复用上下文时仍受调用顺序约束。乘法和符号比较按原32位机器行为。

这一分支无论最终选谁，都把另一结果送聚合器；上一节Y不同分支却维持AUX=0。因此只根据最后选中的位置无法还原最终聚合状态。

## 1F6AC：聚合、提交与持久id

先调用224B4(C,S,AUX)，把返回写u16[C+14]，再写u16[C+0C]=S。两步不受apply参数控制。

apply非零时：S==0不写位置且C+7C=-1；S有80位时提交Pd并把i对应记录的u16 id写C+7C（i==FF则-1）；S无80位时提交Ps并写C+7C=-1。apply为0时不写原P或C+7C，但聚合半字与候选等状态已变化。

这里的0x80是在该流程中为动态结果附加的标记，属性聚合入口会清除它；不能将它推广为原ROM所有属性的统一来源位。C+7C后续经1F3D0按id查回当前列表，再由1F478进行贴边/带动，见[动态矩形报告](semantic-dynamic-rectangles.md)。

## 1F820：另一纵向方向的差异

当T和i至少一路有效时，S/AUX规则与上面形状相似，但apply非零且Y不同时取较大的Y。Y相同或apply==0时仍先测原输入P.x的动态横向范围；未覆盖时改读C+38的静态采样X，并使用对应朝向控制作相同的dx符号选择。C+38由221F0在方向首属性槽为空时记录，与正向220D8的C+30是不同坐标对。

随后调用2253C(C,S,AUX)，写u16[C+16]及u16[C+0E]=S。apply非零且S非零时按80位选择Pd或Ps提交。此函数没有像1F6AC那样更新C+7C，也没有写C+80；不能为其添加看似对称的持久id清理。

2253C只做以下聚合：

```text
B=旧u16[C+16]
S==0：B=0
S有80位：source=S；AUX==0时先B=0
S无80位：source=AUX
source!=0时清其80位；精确F→B|=4，精确E→B|=8，其余→B|=2
返回u16 B
```

与224B4不同，2253C没有后续8000/1000设置/清除，也没有在此合并6000。不能用一个“方向无关属性归并”替代两函数。

## 1F2E8边界预处理与双方无命中

1F2E8(position,C,shape,face,apply)先令u8[C+98]&=F3，清状态位4/8；face参数在可达体中未使用，apply从第五参数读取；取minY=s32[C+8C]、maxY=s32[C+94]。minY>maxY直接返回0。形状为空时取C首指针，通常无溢出域的有效中心范围是：

```text
lo=minY+u16(shape+6)
hi=maxY-u16(shape+4)
```

原代码没有在形状收缩后再验证lo<=hi，以下解释限定lo<=hi及通常坐标域。

- Y在[lo,hi]内：返回0。
- Y>hi：返回正修正量Y-hi，并设C+98的bit4；即使apply非零，本函数也不写回Y。
- Y<lo：返回负修正量Y-lo，并设bit8；apply非零时写Y=lo。

两端并不是完全对称的限幅。1F820在T==0且i==FF时，若该预处理返回值为负，S=40，并在apply非零时提交预处理位置；否则S=0。该无命中路径直接清C+16、写C+0E，不调用2253C，也不更新持久id。正边界修正量不会在这里被同样映射为40或自动应用。

十进制静态例子：有效范围[10,90]，Y=5且apply=1时，边界助手写10、返回-5；若随后两路都无命中，上层返回40并提交Y=10。Y=95则只返回+5、记录bit4；在同样无命中条件下上层返回0，原位置不因该分支自动变为90。例子不代替其他上层路径可能对边界状态的后续处理。
