# 正向纵向静态地形：中心与两侧分段采样

2026-10-29。深化已有地形研究，累计仍20单元。本轮解析1FE4C、1FFE0的采样调度、201C0属性调整及22934回退搜索；同时保存226A8/227C8/22810/2283C原ROM分支，供继续拆解特殊路径。[原始证据](semantic-data/static-edge-sampling-evidence.json)共8个函数，基线SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。未运行游戏、改写正式汇编或干预后台提取。

以下偏移和地址为十六进制，公式常数用0x前缀。坐标24.8：0x100为1像素、0x1000为16像素；低级位移1是1/256像素，不是1像素。本报告不将完整碰撞子系统宣称完成。

## 1FE4C九参数与返回类型

接口暂记为1FE4C(P,other,C,shape,face,pad,policy,collect,apply)。先清u16[C+0C]和u16[C+14]，形状为空时取C首字段；h=u16(shape+4)，中心探测点为：

```text
x=P.x
y=P.y+h+pad
```

返回值始终从u16[C+0C]读取，是经220D8写入的方向首属性槽，不是最后一次修正量，也不是全部采样结果的OR。聚合状态另在C+14，详见[属性聚合报告](semantic-contact-bounds-flags.md)。

## 中心探测与单次位置应用

先调用只查静态格的08EA4(x,y)。只有负修正d才进入中心接触处理，0或正返回不会直接登记属性。负修正后取u16(08D80(x,y))，并调用：

```text
226A8(P,other,x,y,h,pad,policy,apply,d,attribute,0x1400,0x0C01)
```

该助手返回接受的修正d或0；0触发22934特殊回退，不能把0一概当成“已经处于正确位置”。

接受非零d时，采样属性的位置改为(x,y+d+1)，先08D80再201C0调整属性。若局部apply非零，写P.y=y+d-h，然后将局部apply清零。注意没有再减pad，不能用看似对称的式子替换。

若226A8返回0，则22934(P,other,x,y,h,apply,attribute)只有返回负值r时才被本层接受；助手可能已经写P.y，随后本层清局部apply、在(x,y+r+1)取属性。这条回退分支没有经过201C0的同样归一化。两种接受路径最终均调220D8(C,2,sampleX,sampleY,attribute)。

中心接受不代表停止全部采样。collect==0且当前中心属性非零才提前结束；collect非零则继续两侧，即使位置写回已关闭。

## 两侧采样顺序与朝向输入域

未提前返回时，先用dir=2*face-1，长度u16(shape+0)调用1FFE0；再以-dir和u16(shape+2)调用。正常face为0/1时dir为-1/+1；函数没有把任意非零face统一成1，不能泛化这一前提。

首侧返回非零属性时，本层关闭局部apply。collect==0还会跳过另一侧；collect非零继续收集另一侧。两次传入的探测基准y仍是最初计算的y，不能因前面改过P.y就重新计算后续基准。

## 1FFE0的分段与逐像素回退

接口暂记为1FFE0(P,other,C,y,dir,h,length,pad,policy,collect,apply)。length为0直接返回0；正常由u16形状半跨度提供，以下按非负长度解释。

维护总remaining、分段端点cursorX和返回首属性R（初始0）：每轮step=min(remaining,0x1000)，cursorX+=dir*step。在(cursorX,y)调用08EA4。

若修正恰为0，再读08354原始格属性的低四位；低四位非零时触发回退：临时X每次沿-dir移动0x100，同时本段余量减0x100；余量仍>0才把临时X作为新采样点并重新查08EA4，遇到非零修正结束。仅按格低四位触发，不先套用任意8000位过滤。

例如一段16像素到达末端后，可能回查15、14……1像素位置；段余量耗尽时不再读取第0像素点。临时回退不改cursorX，下一段从原分段末端继续。不能把整个算法改成沿边缘每像素平扫。

每轮末尾总remaining固定减0x1000，而不是减回退后剩余量。除非路径提前将remaining清零，否则继续下一段。长度小于16像素时本来只需一段，减后为负正常退出。

## 负修正后的横向调整与收集

08EA4为负时先调227C8(x,y,-dir,本段余量,y-pad)。227C8按08D80属性的8000位选择22810或2283C：前者无位，后者有位。

22810把方向符号转换为0/1，调用20564(...,0x1000)，将返回q转换为：q==0→0；否则m=abs(q)-1，m<=本段限额返回m，超限返回-m。0可能来自q==0，也可能来自abs(q)==1，不能当成纯bool。20564完整内部流程本轮尚未展开。

横向调整量r>0时，采样X再沿-dir移动r，重新取08EA4修正及(y+d+1)点属性，然后仍经226A8选择接受/回退。接受路径与中心相似，调用220D8，并仅在局部apply仍非零时写P.y、随后关闭。函数局部R只在R==0时保存本次属性；如果本次属性也是0，后续仍可能覆盖。

r<=0时不走该接受流程：collect==0且r<0会令总remaining清零，collect非零继续；r==0不会由这条规则提前终止。若最初08EA4返回正值，则另一路直接终止剩余长度。返回值R不是最后样本，不等于整个方向槽C+0C；后者由上层统一读取。

## 201C0：一最小单位上方的原始属性

201C0(x,y,attribute)在低四位为1、E或F时，读取08354(x,y-1)的完整u16属性；若该属性低四位在2..D，返回其完整属性，否则返回原输入的u16值。原输入低四位0或2..D时直接保留。

这是以原始格属性修正某些边界样本，不是再做一次点形状占用判断。上方仅偏移一个定点单位，不能改成上方1像素，也不能只保留替代属性的低四位。

## 22934特殊回退的循环与运动条件

输入属性低四位为0或有8000位时立即返回0。否则先在当前y所属格上方末端((y&FFFFF000)-1)取08D80。若仍为低四位非零且无8000位的占用点，最多再向负Y移六个0x1000格末端；到限制仍找不到空/8000区域则返回0。

找到空/8000点后，从该点加0x100开始逐像素向正Y查08D80，直到低四位非零且无8000位；这段下降循环没有独立的迭代计数。不能把“向上最多六格”误写成整个函数最多六次查询。本轮只读分析，没有执行此搜索。

命中点再减0x100得到candidateY，r=candidateY-输入探测y。要求P.y>=other.y且P.y+r>=other.y，否则返回0。apply非零时写P.y=candidateY-h，返回r。上层只把负r当作接受，助手本身的写回条件与返回符号并不由调用者重新校验后才执行。

## 特殊接受策略的已知边界

226A8的policy=0直接保留d。policy不为0/1时，只有limit>0且d+limit<=0才返回0，否则保留d。本调用limit=1400（20像素）。

policy=1且attribute无8000时，还结合0C01阈值与P.y/other.y运动关系：阈值<=0或d+阈值>0时保留d；否则若P.y<other.y，或P.y+d<other.y，返回0，其余保留d。0C01是12像素加一个最小单位，不能四舍五入成12像素。

policy=1且有8000的分支还会回查历史推导点、格边界和横向2283C追踪。其完整决策树与2283C内部语义留待下一轮；原始可达分支已保存。不能据本报告把全部8000属性命名成某一种平台机制，或声称正向静态碰撞的所有特殊情况已还原。
