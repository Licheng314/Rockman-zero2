# 反向纵向静态采样：分段复用与非对称属性

2026-10-29。深化已有地形研究，累计仍20单元。本轮补齐201F8、202FC、221F0及2290C/22920两层包装的可达语义，对照[正向静态采样](semantic-static-edge-sampling.md)与[特殊接受策略](semantic-special-terrain-policy.md)。[原ROM证据](semantic-data/reverse-static-sampling-evidence.json)保存5个函数，基线SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。没有运行游戏、修改正式代码或干预提取。

以下地址/偏移为十六进制，公式常数带0x；坐标24.8，0x100/0x1000分别为1像素和16像素。数值1是最小定点单位，不是1像素。几何解释限定通常无溢出域；原32位符号/无符号语义仍须保留。

## 201F8：中心点与方向首属性

可按与正向相同的调用槽位记为201F8(P,other,C,shape,face,pad,policy,collect,apply)。但此函数并不使用传入的other位置指针或policy槽位；不能仅因原型类似就假定它执行相同参考位置/策略检查。

先清u16[C+0E]与u16[C+16]；形状为空取C首字段，h=u16(shape+6)，中心点为：

```text
x=P.x
y=P.y-h-pad
d=0901C(x,y)
```

只有d>0进入接触处理。采样属性在(x,y+d-1)由08D80取得；若局部apply非零，写P.y=y+d+h，再清局部apply。此式同样不另加pad。随后调用221F0(C,3,sampleX,sampleY,attribute)。

不像正向1FE4C，这里没有226A8接受策略、22934特殊回退或201C0相邻斜面属性替换。0901C自身仍有形状响应、8000属性过滤和-1耗尽约定，不能将“缺少上层策略”解释为所有高位属性都被忽略。

collect==0且中心属性非零时直接结束。否则以dir=2*face-1和u16(shape+0)调用202FC，再以-dir和u16(shape+2)调用。正常face=0/1分别得到-1/+1；函数不把所有非零值先归一化为1。

第一侧返回非零属性时关闭局部apply；collect==0还跳过另一侧。两侧沿用最初中心点y，不因已修改P.y而重算。最后返回u16[C+0E]，而非某一次位移值、最后一个属性或所有属性的按位或。

## 202FC：16像素分段与1像素回退

接口为202FC(P,C,y,dir,h,length,pad,collect,apply)。length正常来自u16跨度，0直接返回0。维护cursorX、remaining及首返回属性R=0：

```text
step=min(remaining,0x1000)
cursorX += dir*step
q=0901C(cursorX,y)
```

若q==0但08354(cursorX,y)原始格属性低四位非零，则在当前段内沿-dir每次回退0x100，同时段余量减0x100；余量仍>0才重新采样，直到q!=0或段余量用尽。临时回退不改cursorX，后续段仍从原段末端继续。

q>0时调2290C(sampleX,y,-dir,段余量,y+pad)。返回r>0才继续：sampleX+=(-dir)*r，再查0901C得到d，取(x,y+d-1)点属性；局部apply非零时写P.y=y+d+h并关闭局部apply，调用221F0登记，再在R仍为0时保存当前属性。

横向r<=0则不进入此接受路径：r<0且collect==0会终止剩余扫描，r==0或collect非零不据此终止。最初/回退查询q<0则直接终止剩余长度，包含底层-1耗尽返回；q==0正常跳过本段。

每轮末尾总remaining固定减0x1000，并非减回退后的段余量。返回R只保留首个非零样本；属性为0时R仍为0，后面可继续填入。此局部返回值和全方向首属性槽C+0E不必来自同一个样本，因为中心可能已先登记。

## 两层包装实际复用同一横向助手

2290C与22920各自只保存/转发第五栈参数，调用链为：

```text
2290C -> 22920 -> 22810 -> 20564
```

没有像正向227C8那样依据当前属性8000位选择2283C的分支。22810的可达体不读取传入第五参数，因此202FC计算的y+pad并不会通过这条额外参数影响横向助手；pad仍在201F8计算初始y时有作用。

22810将dir符号转为模式、调用20564(...,1000)，q==0返回0；否则m=abs(q)-1，在传入范围内返回m，超出返回-m。abs(q)==1同样得到0。20564内部方向符号、严格距离限制与竖向探针一致性见[特殊策略报告](semantic-special-terrain-policy.md)，这里不把包装名不同误当成另一套独立算法。

## 221F0比正向聚合更简单

输入221F0(C,dir,x,y,attribute)，先按32位清0x80标记。F=u16[C+8+2*dir]，B=u16[C+10+2*dir]：

- 清标记后属性精确0xF：仅F==0时B|=4。
- 精确0xE：仅F==0时B|=8。
- 其他：无条件B|=2。
- 之后F==0则写F=清标记属性，并保存共享(x,y)到C+38/+3C。

与正向220D8相比，这里没有FEC0条件下的状态1、8000设置/清除、6000合并/共享坐标缓存或1000位聚合。完整高位仍可能留在首属性F中，但不意味着B也含同样高位。

例如直接按助手语义推导，初始F=B=0且输入属性8001时，F写8001，B仅为0002；正向220D8同样输入会得到B=8002。这是两助手的静态行为对照，不声称该属性一定能通过201F8的所有底层过滤。

F写0后仍为空，后续可再次写入共享坐标。C+38/+3C不是每个方向各自独立的坐标数组。该采样X随后参与1F820的静态/动态同位仲裁，见[纵向仲裁报告](semantic-vertical-arbitration.md)。

## 正反两路径的已证实差别

| 方面 | 正向1FE4C/1FFE0 | 反向201F8/202FC |
|---|---|---|
| 中心探测 | y=P.y+shape4+pad，08EA4负值 | y=P.y-shape6-pad，0901C正值 |
| 接受策略 | 226A8，必要时22934回退 | 本层不使用policy/other |
| 边界属性调整 | 接受路径可经201C0 | 不调201C0 |
| 横向助手 | 227C8按8000选择22810/2283C | 2290C/22920始终到22810 |
| 内点偏移 | y+d+1 | y+d-1 |
| 属性聚合 | 220D8，多种高位状态 | 221F0，仅类型状态及首属性 |
| 相反符号终止 | 正修正终止余段 | 负修正终止余段 |

共享分段结构不能掩盖这些差异。反向路径及其依赖现均已有可接续解释，水平静态采样和实体对状态字段的实际消费仍需继续。
