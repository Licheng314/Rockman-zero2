## 状态机（arg = 实体，e[0xD] 子状态 0..5，跳表 0x080C5764）

| 状态 | 行为 |
|---|---|
| 0 | **装库 0x9F**：E590[0x9F]=0x300、E390[0x9F]=8；描述符 0x08432D00+0x9F*16+0x27C → **0x08002638 图块** + **0x08002AEC 调色板**（单元 14 接口）；**127E4(e, 0x9F00)** 切库 |
| 1 | 128D4 动画；门 `e[0x18]->[9] & 1` → **127E4(e, 0x9F01)**（同库序列 1）→ 推进 |
| 2 | 128D4；门 `& 2` → 推进 |
| 3 | **装库 0x9E**：E590=0x380、E390=9；**0x080027AC** 图块排队 + 02AEC 调色板；**127E4(e, 0x9E00)** |
| 4 | 128D4；`e[0x54] -= 0x140`（左移）；`0x08015188(0x0202ED18, &e[0x54])` 返回 ≤0xFFF → 推进 |
| 5 | 终态（仅 128D4） |

**语义**：实体驱动的**双库渐变装载序列**（0x9F→0x9E）——装载 → 关联对象标志门禁 →
动画序列切换 → 实体平移 + 边界检测确认。典型 Boss 变身/场景过渡式演出结构。

## VRAM 目标公式（两表值的作用）

```
图块目标   = (E590[库] - 描述符[+6]>>6) << 5 + 0x400     ; 02638 参数
调色板目标 = (E390[库] - 描述符[+7])     << 5 + 0x200     ; 02AEC 参数
```

即 **E590/E390 = 每库的 VRAM/调色板基址运行时映射**（0x300/0x380 为 tile 基址域，
<<5 = 字节化）——与 127E4 的帧索引合成共用同一对表，装载侧与渲染侧在此会师。

## 描述符结构（0x08432D00 族）

- 库条目步长 **0x10**（i*16）+ 偏移族 0x27C；
- 字段对间隔 **0xC**（图块组 [+6] u16、调色板组 [+7] u8——两组成对出现，
  0x08432D00 与 0x08432D0C）——即每库两条 0xC 记录（图块/调色板各一），
  与单元 14 的"12B 图块/8B 调色板记录"同族。

## 关联确认

- 0x08002638/0x080027AC/0x08002AEC = 单元 14 已解的图块/调色板传输接口 ✓；
- 0x08015188 + 0x0202ED18 = 新接口（边界/区域检测，返回值上限 0xFFF），开放；
- 该状态机实体 e[0x18] = 关联对象指针（标志门禁源）。
