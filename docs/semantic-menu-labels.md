## 成长感谢信息与阶段的边界

描述符+3是成长提示类别；0834A660有4个指针，分别为0834A648/0834A650/0834A658/0834A65C。记录每阶段4B，包含两条u16文本引用。EC59C按当前stage读第一条；EC734在升段后按stage-1读对应记录的第二条。

项目6/7的+3为3、最大阶段1：唯一合法阶段记录是0834A65C的[168,16C]，已知文字分别为Thank you和Thanks for / feeding / me + 未定标点 + Zero。不能将同池的174误记为这两个项目的该阶段提示，也不能读取class3的“阶段1记录”：它会越入0834A660指针表。记录长度必须由项目成长域约束，不从相邻地址盲目扩展。

## DE6C8不是普通文字流

ECAD4的箭头/光标显示还调用DE6C8。该函数直接写tilemap，读取NUL结束的字节串：byte<=9F时写入byte+3A0，否则写byte+2E0。DE818则读取FD..FF结束、带F0等控制码的另一种流。两者不可共用同一终止和控制码规则。

DE6C8检查y<=31，并在循环内检查传入x<=31；指令中并未递增保存x的r4，只递增目标指针。因此该检查不是逐字符横向裁剪，也不能保证长串不会越行。当前调用者提供固定短符号串；本轮没有证明任意字符串输入安全。此处为静态代码事实，不修改正式函数或后台提取。
