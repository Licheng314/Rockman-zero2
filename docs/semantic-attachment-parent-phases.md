## 57820使用历史字节决定是否推进随机状态

令last=u8[P+B4]，current=u8[P+D]，seed为0202E188的32位值。其行为分支为：

| 条件 | 下一主状态 | 是否推进seed |
|---|---|---|
| last==current==16 | 17 | 否 |
| last==current，且current既不是15也不是16 | 16 | 否 |
| last==current==15 | high%14<=6则16，否则17 | 是 |
| last!=current | (high&0F)<=7则16，否则17 | 是 |

推进公式为 `seed=(seed*343FD+269EC3)&7FFFFFFF`，high=seed>>16。取余和低位条件是两个分支，不能都简化成同一个“随机一半”。本轮未对真实种子分布或连续选择概率作统计结论。

最后统一执行：P+B4=current，P+D=next，P+E=0，P+F=0。若只按这个助手连续退出、历史字节没有被别处改写，16或17重复两次后会转向另一个候选，而非一直独立随机抽取。外部状态中断或其他历史写入可以改变这一局部前提。

## 同偏移不等于同语义

父对象P+B4在上述选择中以u8读取/写入，保存历史主状态；附着子对象O+B4在A2A30中以32位保存相对X坐标。不能给所有实体统一套用一个B4字段名称或类型。两者共享的是部分实体头部约定，扩展区的用途依实体类型和阶段而异。

这也限制后续C结构还原：不能把父状态选择的字节访问改成子对象的坐标访问，或把子对象记录当作父状态的“上一帧”快照。
