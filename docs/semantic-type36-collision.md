## 槽 11 = 悬停相位

```
A |= 0x20              ; ★ 位 5 = 空中/悬停标志（与地形采样交互的实体状态）
e[0x4D] = 1
e[0x4A] = (e[0x4A] & ~0x31) | 0x20
127E4(e, 0x7200)       ; 库 0x72 续播
```

位 0x20 的语义 = **实体离开地面判定**（悬停/飞行中），与单元 20 地形系统的
实体纵向纠正交互——类型 0x36 攻击轮次含悬停阶段。
