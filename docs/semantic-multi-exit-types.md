# 多组 exit/retire 类型普查与共享退出处理器全解

承接 [相位数组规范布局](semantic-phase-array-layout.md) 与
[类型 0x36](semantic-type36-sm.md)。本轮普查全部多端点类型并全解 exit 处理器。
证据 = [multi-exit-types.json](semantic-data/multi-exit-types.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 多端点类型全普查（5 型）

| 类型 | 相位数 | 端点对 | 各组 own 相位数 | 结构 |
|---|---|---|---|---|
| 0x0B (11) | 23 | @3, @8 | 3 + 3 + 13 扩展 | 双组 + 扩展 |
| 0x21 (33) | 28 | @3, **@16** | 3 + 11 + 9 扩展 | 双组(大第二组) |
| 0x36 (54) | 42 | @3, @8 | 3 + 3 + 32 扩展 | 双组 + 大扩展 |
| 0x3A (58) | 10 | @3, @8 | 3 + 3 | **完整双组**（无扩展） |
| 0x4A (74) | 12 | @3, @8 | 3 + 2 + 2 扩展 | 双组 + 小扩展 |

规范形态：**第一机组 = 槽 0-2 + 端点 3/4；第二机组 = 槽 5-7 + 端点 8/9**
（0x21 例外：第二组 11 相位，端点 @16）。

## 共享退出处理器 0x08065A05 全解

```
exit(e):
  e[0xA] &= ~1                        ; 清标志位 0
  D(e[0xC]) = 4
  e[0x14] = 0x0833D990[e[9]]->[0x10]  ; fn[4] = 共享退役
```

**端点对语义 = 终结链**：exit 装入 D=4 → 下一步退役（0x08006C29 = 双向摘除+
空链回压，即[对象池](semantic-object-pool-census.md)回收）。即端点对不是
"两个分支"而是**顺序终结序列**。

## 双机组进入路径（开放 + 已知线索）

- **D=5（第二组起点）的直写者不在任何 own 处理器内**（5 型 40 个处理器扫描
  零命中）——进入第二组的路径经：外部代码（谓词 0x08065A24 = C 集成 #4 的
  D 切换族）、或 D=5 由 0x08345998 生命周期侧写入；
- 已知线索（type 0x3A fn1 = 0x080873AC 全解）：正弦摆动飞行（0x080EF450 +
  e[0x12] 步进 3 + e[0x5C] 振幅递增钳 0x1F）+ **属主门**：
  `owner[0xD] ∈ {0x18, 5}` → D=2 + e[0x14]=fn[2]——实体行为随属主状态切换，
  属主驱动的相位变迁是第二组进入的候选通道。

## 语义结论

多端点数组 = **同一实体的两段独立生命周期**（形态一/形态二，如 Boss 变身）：
第一段可经 exit→retire 终结（被消灭），第二段（D=5 起）独立运行、独立终结
（端点 8/9）。5 型均为大型敌人（0x36 自复制 Boss、0x21 大第二组）。
