# Boss 精灵帧→图块→资产链（结构通、末环开放）

承接 [库 0x62/0x72 动画表](semantic-lib72-frames.md)。本轮打通 Boss 精灵
"帧→图块→VRAM"结构链并定位资产对接的末环。原 ROM 基线
SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 结构链（已通）

```
库 0x72 动画流(帧号 0-0x23)
  → 帧头表 0x08414B00[0x72] = 0x084276EC（36 帧头: u16 偏移+u8 数量+u8 变体）
  → 图块列表(帧头表+偏移): 每图块 8B = OAM attr0/attr1/attr2 + dx/dy
     帧 0 = 4 图块（待机小姿态）; 帧 1+ = 10 图块（大体态）
     attr2 低 10 位 = VRAM tile 号（0x004/0x002/0x000/0x022…）
  → VRAM 基址 = e+0x48 合成索引（E590[库]+e[0x20]，127E4 装载）
```

实测帧 0 图块：attr2 tile 号 {4,2,0,0x22}，dx/dy 拼合 (-3,-16)/(-12,0) 等
——Boss 由多 OAM 项拼合，两行排布（dy=-16/0）。

## 末环（开放）：0x084CC680 记录目录

动态路径（e[0xB]&4）的图块数据经 **0x084CC680 记录目录**（单元 14/15 已解
读取侧：按 bank 范围选 12B 图块记录或 20B 图块/调色板记录 → 027AC 排队/
02AEC 调色板）。本轮实测目录前几个 12B 三元组：

```
(0x324, 0x1070, 0x1A84), (0x3C04, 0x4A24, 0x6374), …
```

值单调递增——疑似 (块大小/偏移, 未压缩量, 累计) 三元组，但与
assets/lz77_index.tsv 的 (compressed, uncompressed) 无连续匹配
（804B 压缩块在索引中不存在）——目录指向的 blob 可能为
**原始图块/RLE 混合**（单元 14 的 LZ/RLE 分支）而非纯 LZ77，
或基址需经 02638 装载器的基址运算。
