## 语义修正

旧解读"0x083412D0 起 = 备选集（运行时切换）"**不成立**——实际是
**逐相位碰撞目录**：每个攻击相位自装自己的碰撞描述符 + 动画序列 +
帧计时（相位 → 描述符 → 库 0x72 序列 三位一体）。碰撞几何随攻击动作
变化（18×20px / 12×24px / …），即 Boss 各招式各有判定盒。

这也解释了多桶设计：不同相位登记不同分类组合（接触/受击/攻击通道）。

## 附加收获

- 库 0x72 的**序列号 = 相位号**模式浮现（槽 10→0x7200、槽 12→0x7203）——
  19 个脚本 ≈ 主扩展机各相位的动画序列一一对应；
- 槽 5（子机组）也装 0x083412D0——子机组与主扩展机共用基础碰撞。
