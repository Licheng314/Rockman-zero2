# 库 0x62/0x72 动画表：Boss 精灵帧域揭示

承接 [配对表](semantic-type36-pairing-table.md)。本轮解码类型 0x36 所用两库的
资源块内容。证据 =
[lib72-frames-check.py](semantic-data/lib72-frames-check.py)（6/6 通过）+
[lib72-frames-evidence.json](semantic-data/lib72-frames-evidence.json)。
原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。

## 库 0x72（类型 0x36 主动画库）

- 条目数组 @0x08431CAC，**29 条目**（0x7200-0x721C 可用域，配对表用了其中
  0x7200-0x7212+0x721C 共 16 个）；
- **帧号域 0x00-0x23 = 36 帧 Boss 精灵**（时长 1-8 帧/帧）；
- 流格式与 [帧步进器](semantic-anim-sequence-stepper.md) 一致：
  `(时长<<8)|帧号` + 0xFF00 保持 + 0xFE00 跳转；
- 典型结构：seq0 = 帧 0x00 保持（待机定格）→ 0x0300/0x0309/…（摆动循环）；
  攻击序列含 0xFE00 回跳（往复动画）。

## 库 0x62（启动组小库）

- 条目数组 @0x08431710，**4 条目**——init（槽 0）的 0x6201 用其小动画
  （帧 0x00 保持 + 0x1A 帧循环）——入场专用极简库。

## 结构链完整

```
类型 0x36 相位 → 127E4(0x72xx) → 库 0x72 条目数组[seq]
  → 动画流(36 帧 Boss 精灵) → 04B9C 步进 → 帧号 → OAM
```

29 序列）→ 帧（36 帧 Boss 精灵）。
