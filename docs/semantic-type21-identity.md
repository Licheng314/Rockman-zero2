# 类型 0x21 身份确认：变体 1 攻击体银行宿主

承接 [类型 0x36](semantic-type36-sm.md) 与 [变体 1 攻击体银行](semantic-variant1-attack-bank.md)。
本轮解码类型 0x21（28 相位）相位数组，**确认其 = 变体 1 攻击体银行的宿主类型**——
两条研究线的归属在此闭合。原 ROM 基线 SHA1 c4d93a58f0f82c526dec8a3fdbda170336303689。
