# 15188：摄像机矩形超出量，不是环绕

2026-11-01审计纠正。旧稿遗漏了非负差值分支的常量扣减，并把负差值处理误称为半屏模量环绕。

对32位回绕后的有符号坐标差dx、dy，返回max(0,abs(dx)-0x7800,abs(dy)-0x5000)。它读取摄像机当前显示中心，不产生对象从另一侧进入的环绕行为。

权威语义与2163组原ROM局部执行见[环境报告](semantic-parent-environment.md)，摄像机结构见[摄像机报告](semantic-camera.md)。旧wrap-boundary-check.py只能证明片段存在，不能支持环绕结论；不再用其8/8作为几何行为验证。
